## Getting Started

### Prerequisites

- Python 3.12+ (build script 3.12–3.14 yollarını arar)
- Windows (Tk + bat scriptleri)
- İnternet (TCMB XML)

### Setup

```bash
cd "c:\Users\Asus.DESKTOP-9F6EQVL\Desktop\tools\gelir_hazırlama"
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
# Suite PySide sayfası için ayrıca: pip install PySide6
```

### Run Locally

```bash
run_app.bat
# veya
python gelirhazirlama.py
```

### Build EXE

```bash
build_exe.bat
# çıktı: dist\GelirHazirlama.exe
```
